# Monthly Calendar

A responsive monthly calendar built with React, Vite, and TypeScript. The app highlights today, weekends, and adjacent month days while keeping navigation simple on desktop and mobile screens.

## Available scripts

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
